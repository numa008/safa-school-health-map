# Dashboard Mockup

The planned dashboard will help users view school-level waste-linked climate-health exposure risks.

## Core Views

1. School risk map
2. School vulnerability scorecard
3. Waste hotspot layer
4. Open-burning report layer
5. Recommended interventions
6. Pilot progress dashboard

## Example School Scorecard

| Indicator | Status |
|---|---|
| Distance to landfill | High risk |
| Open-burning reports | High |
| Visible waste nearby | Medium |
| Collection coverage | Low |
| Overall risk category | Critical |

## Example Recommendation

This school should be prioritized for baseline waste audit, community hotspot monitoring, recyclable collection setup, and municipal follow-up on nearby open burning.
